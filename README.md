# ネットワーク攻撃シミュレータ ver. 2

ネットワークを攻撃(ノードを逐次除去)したときの分断の様子を可視化します．<br>
計算はすべてブラウザ内で完結します(Pyodide 上の NetworkX を使用)．

## 機能

- **ネットワークの読み込み**: 同じディレクトリに置いた `.net` ファイルをドロップダウンから選択して読み込む
- **攻撃方法**: ランダム故障，HD攻撃(次数順，再計算なし)，RB攻撃(媒介中心性を毎回再計算し最大のノードを除去)の 3 種類
- **可視化**:
  - ネットワーク図(連結成分のハイライト，スライダー / アニメーションで崩壊過程を再生)
  - 最大連結成分サイズ比 $S(q)/N$ の曲線
  - 第二最大連結成分サイズ $\langle s \rangle$ の曲線
- **指標**: 頑健性指標 $R$ と臨界値 $q_c$ を算出
- 数式は KaTeX でレンダリング

## 使い方

ネットワークデータを `fetch` で取得するため，`file:` で直接開くのではなくローカル HTTP サーバー経由で開いてください．

```bash
cd net-attack-demo
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

初回は Pyodide(ブラウザ内 Python)のダウンロードに数十秒かかることがあります．

1. 「ネットワークデータ」からファイルを選択
2. 「攻撃方法」を選択
3. 「実行」をクリック
4. スライダーまたは「再生」(約 10 秒のアニメーション)で崩壊過程を観察

## ファイル構成

```
index.html              ページ構造
style.css               スタイル
app.js                  アプリ本体(UI・描画・Pyodide 連携，Python コードを内包)
networks.json           読み込み可能なネットワークの一覧
*.net                   ネットワークデータ(Pajek 形式)
```

## ネットワークの追加方法

1. [Pajek](https://ds9.jaist.ac.jp/ResearchData/presen/Pajekman.pdf) 形式の `.net` ファイルを `index.html` と同じディレクトリに置く
2. `networks.json` にエントリを追加する

```json
{
  "networks": [
    { "file": "mynetwork.net", "label": "表示名" }
  ]
}
```

読み込み時の扱い:

- NetworkX の `parse_pajek` で読み込み，**無向単純グラフ**に変換(多重リンクと自己ループは除去し，リンクの向きは無視)
- 頂点行に座標があればレイアウトに利用し，なければ spring layout を計算

## 実装メモ

- 除去順序を逆再生しながら union-find でノードを追加していくことで，全ての $q$ に対する成分サイズをほぼ $O(N+E)$ で計算
- スライダー操作時の成分分解は JS 側の union-find で再計算しており，Python の再実行が不要
- RB攻撃の実行は少し時間がかかる点に注意
